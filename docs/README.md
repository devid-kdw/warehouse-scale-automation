# Documentation Index

## Authority Order

If documents conflict, use this precedence:
1. `docs/team/RULES_OF_ENGAGEMENT.md`
2. `docs/team/DECISIONS.md`
3. active planning input (`docs/tasks/TASK-0020-ui-feedback-master-plan-input.md`)
4. active implementation plan (`docs/tasks/TASK-0021-v3-implementation-master-plan.md`)
5. historical task/status documents
