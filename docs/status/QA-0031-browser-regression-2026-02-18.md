## Identified Issues

### 1. [FAIL] T05 - i18n Gaps (Severity: LOW)
- Multiple UI elements still use English labels (e.g., in Settings, some tooltips).
- **Recommendation:** Complete the translation mapping in `i18n.ts`.

### 2. [BUG] T08 - Order Creation Failure (Severity: MEDIUM)
- The frontend `CreateOrder.tsx` fails with a 422 error from the backend because it attempts to create an order without line items, which the backend schema validation rejects.
- **Recommendation:** Update frontend to either allow empty orders or ensure at least one line item is added before submission.

### 3. [FAIL] T18/T19 - RBAC Settings Leak (Severity: HIGH)
- The `OPERATOR` role should not see or have access to the `Postavke` module.
- Observations: Link is visible in sidebar, and manual navigation to `/#/settings` is allowed.
- **Recommendation:** Implement route protection for `/settings` and conditional rendering for the sidebar link based on user role.
